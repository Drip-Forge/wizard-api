# wizard-api documentation

Wizard is a three-repo toolkit that helps open-source maintainers join [Drips](https://drips.network): claim a GitHub project with `FUNDING.json`, and optionally split incoming streams toward dependencies.

## Read in this order

1. [Architecture](architecture.md) — where this service sits relative to the UI and contracts
2. [HTTP API](api.md) — `GET /health`, `GET|POST /analyze`, response shapes, errors
3. [Drips integration](drips-integration.md) — how the output maps onto Drips claim + splits
4. [Contributing](../CONTRIBUTING.md) — local setup and Drips Wave workflow
